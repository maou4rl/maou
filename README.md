# Maou — Bot Developer Portfolio 

A single-page portfolio focused entirely on bot and automation work — Telegram, Discord, WhatsApp, and AI-powered chat agents. 


---

## About

Unlike my main portfolio, this site is scoped strictly to bots and automation — no general web dev, no UI/UX case studies. It's meant for clients and collaborators specifically looking for bot work.

## Built With

- HTML5 / CSS3
- Vanilla JavaScript
- Google Fonts — Space Grotesk / Inter 
- Inline SVG icons (GitHub, X/Twitter, LinkedIn)
- Hosted on GitHub Pages

## Sections

- **Hero** — intro and availability status
- **What I Do** — bot categories at a glance
- **About** — bio + bot-specific tech stack (Telegram Bot API, Discord.js, WhatsApp API, FastAPI, LLM integration)
- **Selected Work** — Telegram bots, Discord bots, WhatsApp automation, AI chat agents
- **Services** — what's offered to clients
- **Contact** — email + social links
